# 사용자 접근·권한 정책

## 역할

| 역할 | 권한 |
| --- | --- |
| admin | 사무실 업무 전체 처리, 멤버 관리·비활성화 |
| staff | 매물·상담·계약·오늘 할 일·광고비 업무 처리 |
| inactive | 로그인해도 업무 데이터 접근 불가 |

## 공통 정책

- 로그인은 Clerk로 처리한다.
- 서버는 Clerk 사용자와 활성 `organization_members`를 확인한다.
- 업무 데이터에는 모두 `organization_id`를 둔다. 브라우저가 보낸 조직 ID는 신뢰하지 않는다.
- 기본 시작 화면은 오늘 할 일(`/dashboard`)이다.
- 다른 조직·비활성·미로그인 사용자는 업무 데이터를 읽거나 바꿀 수 없다.

## 민감 정보

연락처, 출입 비밀번호, 열쇠 위치, 내부 메모는 상세 업무에 필요한 경우만 접어서 보인다. 기본 매물 목록·오늘 할 일·일반 내보내기에는 포함하지 않는다.

## 확인 기준

- [ ] admin과 staff가 자기 조직 업무를 처리한다.
- [ ] inactive와 멤버 없음 계정이 차단된다.
- [ ] 다른 조직 ID를 주소에 넣어도 데이터를 볼 수 없다.
