# 개발 환경 운영 계획

> 기준일: 2026-08-26

## 환경 구분

| 환경 | Clerk | Supabase | 데이터 |
| --- | --- | --- | --- |
| Local | Development | Dev | 가공 데이터만 |
| Preview | Development 또는 별도 Preview | Dev와 분리된 Preview 권장 | 가공 데이터만 |
| Production | Production | Production | 수용 테스트 뒤 실제 데이터 |

## 규칙

- `.env.local`은 Git에 올리지 않고 값도 출력하지 않는다.
- Production과 Dev의 프로젝트·키·사용자는 분리한다.
- Dev DB 초기화는 새 migration 작성 뒤 사용자의 명시적 승인으로만 한다.
- 기존 Streamlit SQLite와 Production DB는 개발 작업의 대상이 아니다.
- 기본 브랜치는 `main`이며, 배포·푸시·원격 DB 변경은 별도 승인 작업이다.

## 재빌드 시작 확인

- [ ] Local Clerk와 Supabase Dev 연결값이 있다.
- [ ] Local에서 실제 데이터 없이 빈 앱을 실행한다.
- [ ] Preview가 Production 데이터에 연결되지 않는다.
- [ ] secret/service-role 키가 브라우저 코드에 없다.
