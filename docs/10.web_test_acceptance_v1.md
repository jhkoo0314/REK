# 테스트·수용 기준

## 기록 방법

각 항목을 PASS, FAIL, BLOCKED로 기록한다. 코드 검사 통과와 브라우저에서 직접 확인한 결과를 구분한다. Blocker와 Critical 오류가 남아 있으면 다음 단계 또는 운영 전환을 진행하지 않는다.

## P0 필수 테스트

- [ ] 미로그인·inactive·다른 조직 계정이 업무 데이터를 볼 수 없다.
- [ ] 새/기존 건물과 호실로 매물을 등록한다.
- [ ] `302`와 `302호`, 같은 호실의 현재 매물 중복이 막힌다.
- [ ] 잘못된 금액·날짜·필수값이 저장되지 않는다.
- [ ] 검색·필터·상세·수정·빠른 수정이 목록에 반영된다.
- [ ] 일반 수정 뒤 새 매물이나 연결 기록이 생기거나 사라지지 않는다.
- [ ] 매물 목록과 오늘 할 일 기본 표에 민감 정보가 없다.
- [ ] 같은 조직의 건물·호실 상세에서만 연락처·출입 정보를 명시적으로 열람·수정할 수 있다.
- [ ] 제한 정보는 다른 조직·inactive 계정에 보이지 않으며, MVP 화면에 Excel·CSV 다운로드 기능이 없다.

## P1 필수 테스트

- [ ] 일반 상담·매물 상담·고객 연락처·희망 조건·후속 이력·다음 연락일이 정상 동작한다.
- [ ] 현재 같은 조직의 active admin·staff는 상담 기본 목록에서 고객 연락처를 보고, 다른 조직·매물 목록·오늘 예정 업무·광고에는 보이지 않는다.
- [ ] 후속 이력을 추가·수정·삭제하면 최신 이력·다음 연락일·진행 단계 요약이 다시 계산된다.
- [ ] 상담 화면에서 계약 진행·계약 완료를 선택하거나 변경할 수 없다.
- [ ] 계약의 실제 계약 매물과 출처 상담이 정상 연결된다.
- [ ] 계약 진행·완료·해지·만료 상태 반영은 계약관리의 확인 뒤에만 실행된다.
- [ ] 오늘/지연 업무와 완료 체크가 원본을 바꾸지 않는다.
- [ ] 월별 플랫폼 광고비가 같은 월·플랫폼에 중복 저장되지 않고, 월 합계가 정확하다.
- [ ] active admin·staff가 유형별 읽기 전용 기본 광고 문구를 선택해 확인한 값으로 제목·본문을 만들고 복사할 수 있다.
- [ ] 템플릿 선택·복사로 매물·광고 상태가 바뀌지 않고 민감정보가 문구에 포함되지 않는다.

## 운영 전환 테스트

- [ ] admin/staff/inactive/멤버 없음/다른 조직을 검증한다.
- [ ] PC와 휴대폰 핵심 흐름을 확인한다.
- [ ] Production RLS, 환경 분리, 로그인 redirect, 비밀 키 노출 여부를 검증한다.
- [ ] 실제 데이터를 넣기 전 Blocker·Critical이 0건이다.
