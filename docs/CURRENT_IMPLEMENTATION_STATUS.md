# 현재 구현 상태

> 최종 갱신: 2026-08-26
>
> 이 문서는 “실제로 구현·확인한 것”만 기록한다. 계획이나 작성 예정 migration은 완료로 적지 않는다.

## 현재 단계

- 재빌드 준비 완료
- 다음 작업: 0단계 — 새 Next.js 프로젝트 기반, Clerk Development 로그인, 공통 App Shell

## 현재 구현된 기능

- 아직 없음. 이전 웹 코드와 이전 migration·seed는 재빌드 기준으로 제거했다.

## 문서·설정 상태

- 재빌드 범위, 폴더 구조, 단계별 TODO, 1~13 기준 문서를 새 기준으로 정리했다.
- Supabase 원격 설정과 Clerk 원격 설정은 보존했다.
- Dev DB 초기화, 새 migration 작성·적용, RLS 변경, 배포는 하지 않았다.

## 최근 확인 결과

| 항목 | 결과 | 비고 |
| --- | --- | --- |
| 기존 웹 코드 삭제 | 완료 | 재빌드를 위해 제거 |
| 기존 로컬 migration·seed 삭제 | 완료 | 새 P0 모델 기준으로 다시 작성 예정 |
| 문서 형식 검사 | 통과 | `git diff --check` |
| 앱 lint/typecheck/build | 미실행 | 새 프로젝트 코드가 아직 없음 |
| 브라우저 확인 | 미실행 | 새 화면이 아직 없음 |

## DB 적용 상태

| 대상 | 상태 |
| --- | --- |
| 로컬 migration 파일 | 없음 — 새 P0 설계 뒤 작성 |
| Supabase Dev DB | 변경하지 않음 |
| Supabase Production DB | 변경하지 않음 |
| Clerk Development / Production | 변경하지 않음 |

## 다음 작업과 승인

1. 0단계 프로젝트 기반과 로그인·공통 화면을 구현한다.
2. 1단계에서 P0 데이터 모델과 migration 파일을 작성한다.
3. Dev DB 초기화·migration 적용은 파일 검토 후 사용자 승인이 필요하다.

## 갱신 양식

각 단계 종료 때 아래 항목을 추가한다.

```text
### 단계 또는 기능명 — 완료일
- 구현: 실제로 만든 화면·서버 처리·공통 부품
- DB: migration 작성 / Dev 적용 / 변경 없음

- 남은 작업: 다음 TODO 항목과 사용자 승인 필요 여부
```
