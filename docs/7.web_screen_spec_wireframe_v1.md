# 화면 명세·디자인 적용 기준

## 디자인 기준

세부 시안은 `docs/Design_guide/`를 따른다. Inter 본문, Roboto Mono 숫자, 승인 색상·여백·상태 배지를 사용한다. 한 화면의 주요 행동 버튼은 하나만 강조한다.

## 메뉴와 주소

| 메뉴 | 주소 | 단계 |
| --- | --- | --- |
| 오늘 할 일 | `/dashboard` | P1 |
| 매물 목록 | `/listings` | P0 |
| 신규 매물 | `/listings/new` | P0 |
| 매물 상세/수정 | `/listings/[id]`, `/listings/[id]/edit` | P0 |
| 건물·호실 | `/buildings` | P0 |
| 상담 | `/consultations` | P1 |
| 계약 | `/contracts` | P1 |
| 광고비·문구 | `/advertisements` | P1 |

## 화면 공통 상태

모든 실제 업무 화면에 로딩, 데이터 없음, 오류, 저장 중, 권한 없음, 확인 창을 제공한다.

## 목록 원칙

- 매물 목록: 상태·건물·주소·호실·구조·가격·입주 조건 등 판단용 정보만 표시한다.
- 연락처·비밀번호·내부 메모는 기본 목록에서 숨긴다.
- PC는 표, 휴대폰은 카드로 같은 데이터를 제공한다.
- 상세는 민감 정보를 접고, 연결 상담·계약 요약을 보여 준다.

## 화면 완성 기준

각 화면은 디자인 가이드와 같은 정보 위계, 모바일 핵심 확인, 오류·빈 상태, 공통 부품 재사용을 모두 만족해야 한다.
