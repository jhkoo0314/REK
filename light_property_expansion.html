부동산 유형별 기능 확장 설계 (Expansion Blueprint)

원/투룸 → 아파트, 오피스텔, 상가/사무실 유연한 확장 UI 가이드

확장 컴포넌트 설계 완료
architecture 확장 디자인 핵심 원칙 (Architecture Concept)

기존 화면 구조를 깨지 않고, 부동산 유형별 특화 항목을 "동적 컴포넌트"로 스위칭

모든 부동산(원룸, 아파트, 상가, 오피스텔)은 **`건물 → 호실 → 매물`** 기본 관계를 100% 공유합니다. 유형 확장 시 화면 전체를 새로 만들지 않고, 1) 카테고리 탭 2) 유형별 맞춤 필터 3) 동적 입력 폼(권리금/업종/주차)만 조립형으로 전환되도록 설계합니다.

1. 매물 목록 상단 카테고리 탭 & 유형별 동적 필터 디자인

카테고리를 클릭하면 아래 필터 바의 검색 항목이 해당 유형 특화 조건으로 자동 변경됩니다.

tune 상가/사무실 특화 필터 조건 권리금 / 업종 / 전력용량 / 1층 여부 선택 가능

2. 부동산 유형별 테이블 열(Column) 동적 변형 예시

상가 선택 시 '권리금/추천업종/전기' 항목이 테이블 주요 열로 즉시 전환됩니다.

3. 매물 등록 위저드 Form (Step 3) 동적 세부 항목 설계

매물 유형 선택에 따라 Form 하단에 전용 스키마 입력란이 생성됩니다.

🏠 원/투룸/빌라 전용 항목 기본
  • ✅ 풀옵션 선택 (세탁기/냉장고/에어컨)
  • ✅ 관리비 포함 항목 (인터넷/수도)
  • ✅ 주차 가능 대수 & 엘리베이터 여부
🏢 아파트 / 오피스텔 전용 항목 확장
  • ✅ 공급면적 / 전용면적 / 평형 선택
  • ✅ 방 수 / 욕실 수 / 베란다 확장 여부
  • ✅ 주거용 vs 업무용 구분 (오피스텔)
  • ✅ 세대당 주차대수 & 난방 방식
🏪 상가 / 사무실 전용 항목 확장
  • ✅ 권리금 (금액 / 무권리금 / 협의)
  • ✅ 추천 및 허가 가능 업종 태그 입력
  • ✅ 전력 용량(kW) & 수도/배수/닥트 여부
  • ✅ 남녀 분리 화장실 & 전면 간판 위치
