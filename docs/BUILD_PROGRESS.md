# 웹 재빌드 진행 현황

> 최종 갱신: 2026-08-25
>
> 기준: `REBUILD_MASTER_SPEC.md`

## 현재 상태

- Streamlit 시스템을 기준으로 웹을 처음부터 다시 구현하기로 결정했다.
- 기존 Next.js 코드·가공 화면·기존 기능 구현은 재사용하지 않는다.
- Clerk·Supabase의 원격 설정, 로컬 `.env.local`, `docs/Design_guide/`, 문서와 Git 이력은 보존한다.
- 기존 로컬 migration과 seed는 재빌드 기준으로 삭제했다. Dev DB의 초기화·새 migration 적용은 아직 승인되지 않았다.
- 기존 Streamlit SQLite 데이터는 읽기 전용으로 보관하며 자동 이관하지 않는다.

## 이번 재빌드에서 확인한 사항

- 기존 웹 구현은 매물 P0 일부와 가공 화면이 섞여 있어, Streamlit 기능 기준으로 이어서 확장하면 문서·데이터·화면 기준이 달라질 위험이 있다.
- 따라서 코드만 비우고, 새 기준서와 실행 목록을 먼저 작성한 뒤 P0부터 다시 구현하는 방식이 적절하다.
- Streamlit의 광고 기능은 매물별 광고 상태가 아니라 월별 광고비와 직접입력형·비저장 문구 생성이다.

## 다음 안전한 작업

1. 코드 삭제 뒤 새 Next.js 기반을 만든다.
2. 승인 디자인 가이드에 맞춰 로그인·공통 App Shell과 상태 UI를 구현한다.
3. P0 데이터 모델을 최종 검토하고 새 migration 파일을 작성한다.
4. 사용자의 별도 승인 후에만 Dev DB 초기화·migration 적용·가공 seed를 실행한다.

## 확인 결과

- 이번 작업은 문서 재작성과 코드 삭제 준비만 포함한다.
- DB migration 적용, RLS 변경, 배포, Git push, 실제 데이터 입력은 수행하지 않았다.
