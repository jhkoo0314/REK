# 업무 워크플로우 명세

## 공통 저장 흐름

로그인 사용자 확인 → 활성 조직 확인 → 입력 검증 → 같은 조직 데이터인지 확인 → 저장 → 목록/상세 갱신. 오류는 쉬운 한국어로 해당 입력칸 근처에 표시한다.

## 매물

1. 기존 건물·호실을 찾거나 새로 입력한다.
2. 현재 매물 중복 여부를 화면과 DB에서 확인한다.
3. 가격·상태·입주 조건·확인 업무를 저장한다.
4. 이후 일반 조건 변경은 같은 현재 매물을 수정한다.
5. 목록 빠른 수정은 상태 변경과 관리 종료만 허용한다. 계약 진행·계약 완료는 매물 화면에서 변경하지 않고 계약관리에서만 처리한다. 계약관리의 확정 결과가 해당 매물을 `contract_in_progress` 또는 `contract_complete`·`is_current = false` 과거 이력으로 전환한다.
6. 매물을 없애야 할 때는 실제 삭제 대신 상세 화면의 `관리 종료`를 사용한다. 확인창에서 새 매물 등록 가능·과거 이력 보존 영향을 설명한 뒤, 사용자가 확정하면 `ended` 상태와 과거 이력으로 전환한다. 상담·계약 기능을 추가한 뒤에는 연결 건수와 영향도 함께 표시한다.

## 상담

1. 일반 상담 또는 최초 문의 매물 연결 상담을 만든다. 일반 상담은 나중에 최초 문의 매물을 연결할 수 있다.
2. 고객 식별명·연락처, 유입 경로, 상담 방식, 희망 지역·방 구조·예산·입주일·필수 조건을 저장한다. 고객 연락처는 같은 조직 직원의 상담 목록과 상세에서 기본 표시한다.
3. 상담 상태(`진행 중`·`보류`·`종료`·`확인 필요`)와 진행 단계(`신규 문의`·`조건 확인`·`방문 예정`·`방문 완료`·`검토 중`·`종료`)를 따로 관리한다.
4. 통화·문자·방문·기타 후속 이력에 일자·방문 결과·종료 사유·다음 연락일·메모를 누적한다. 이력을 추가·수정·삭제하면 상담의 최신 요약을 다시 계산한다.
5. 상담을 종료하면 다음 연락일을 해제한다. 다음 연락이 24시간 이내면 최우선, 72시간 이내면 추가 집중 대응으로 표시한다.
6. 계약 진행·완료는 상담에서 바꾸지 않는다. 계약 완료가 계약관리에서 확정되면 출처 상담을 종료하고 다음 연락일을 해제한다.

## 계약

1. 실제 계약 매물을 반드시 선택하고, 출처 상담은 선택한다.
2. 계약 일정·금액·중개 방식·상태를 저장한다.
3. 단계 이력은 기존 계약 정보를 덮어쓰지 않고 누적한다.
4. 계약 상태 또는 계약 단계 이력을 저장하면 연결된 실제 계약 매물 상태를 자동 반영한다. `계약 진행`·`잔금 예정`은 현재 매물을 `contract_in_progress`로, `계약 완료`는 `contract_complete`·`is_current = false` 과거 이력으로 전환한다.
5. `해지`·`만료`는 아직 종료되지 않은 `contract_in_progress` 매물만 `vacant`로 되돌린다. 이미 계약 완료·관리 종료된 과거 이력은 자동으로 다시 열지 않는다.
6. 정식 계약일·계약금 추가 수령 예정일·잔금 예정일·임대차 종료일은 오늘 예정 업무를 만드는 일정이다. 날짜만 지났다고 계약·매물 상태를 자동 변경하지 않는다.

## 오늘 할 일

퇴실·계약 일정·상담 다음 연락일을 오늘/지연으로 계산한다. 완료 체크는 계산된 업무만 저장하고 원본 상태나 날짜를 바꾸지 않는다.

## 광고 관리

1. admin 또는 권한이 있는 직원이 기준연월, 플랫폼, 월 총 광고비, 메모를 입력한다. 같은 월·플랫폼이 있으면 새 항목을 만들지 않고 기존 금액을 수정한다.
2. 화면은 선택한 월의 플랫폼별 비용과 전체 합계를 보여 준다. 이 기록은 향후 플랫폼별 가성비 분석의 기준 자료이며, 현재는 매물·상담·계약과 자동 연결하거나 성과를 계산하지 않는다.
3. 직원은 원룸·투룸, 아파트, 오피스텔, 상가·사무실 유형별 읽기 전용 기본 템플릿을 선택한다.
4. 직원은 매물 유형에 맞는 템플릿을 선택하고 확인된 매물 값만 채워 제목·본문을 확인·필요 시 수정·복사한다. 템플릿 선택·복사로 매물 또는 광고 상태는 바뀌지 않는다.
5. 연락처, 출입 비밀번호·출입 메모, 내부 메모는 템플릿과 결과에 넣지 않는다.

## 자료 반출과 민감정보

MVP에서는 Excel·CSV 다운로드를 제공하지 않는다. 매물·상담·계약·오늘 할 일은 웹 화면의 검색·필터·상세 보기로 처리한다. 자료 반출 또는 직원별 민감정보 열람 제한이 필요해지면 admin이 멤버별로 권한을 정하는 별도 보안 작업으로 구현하며, 기본값은 민감정보 숨김과 다운로드 금지다.
