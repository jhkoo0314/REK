# Production 배포·운영 시작 체크리스트

## 배포 전

- [ ] P0·P1 기능과 수용 테스트가 통과했다.
- [ ] Clerk Production, Supabase Production, Vercel Production을 Dev와 분리했다.
- [ ] Production 환경변수와 로그인 redirect URL을 확인했다.
- [ ] 실제 데이터가 Dev·Preview에 없음을 확인했다.

## 보안 전환

- [ ] Clerk–Supabase Native Integration을 연결했다.
- [ ] 모든 업무 테이블 RLS를 활성화했다.
- [ ] 조직별 SELECT·INSERT·UPDATE·DELETE와 `WITH CHECK`을 검증했다.
- [ ] admin/staff/inactive/다른 조직/미로그인 접근을 확인했다.
- [ ] 일반 CRUD와 브라우저에 secret/service-role 키가 없다.

## 운영 시작

- [ ] 기존 Streamlit SQLite 원본은 읽기 전용으로 안전하게 보관한다.
- [ ] 웹의 실제 데이터는 새로 등록한다. 자동 이관하지 않는다.
- [ ] 첫 건물·호실·매물 → 상담 → 계약 → 오늘 할 일 흐름을 확인한다.
- [ ] 장애 시 Streamlit으로 임시 전환하면 전환 시점과 업무를 별도 기록한다.

최종 승인은 Blocker·Critical 0건, RLS 조직 분리 통과, 담당자 확인이 모두 있을 때만 한다.
